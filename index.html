📋 Anleitung für den Administrator:

Die Firebase-Konfiguration muss einmalig im Code hinterlegt werden.

  1. Firebase Projekt erstellen (falls noch nicht geschehen)
    → Firebase Console
  2. Realtime Database aktivieren
    → Build → Realtime Database → Datenbank erstellen
  3. Konfigurationsdaten kopieren
    → Projekteinstellungen (Zahnrad) → Scrolle zu "Ihre Apps" → Web App hinzufügen
  4. Code bearbeiten
    → Öffne die index.html Datei in einem Texteditor
    → Suche nach: FIREBASE_CONFIG
    → Ersetze die Platzhalter mit deinen echten Werten
  5. Änderungen hochladen
    → Speichere die Datei
    → Push zu GitHub (oder Firebase Hosting)

💡 Beispiel:

const FIREBASE_CONFIG = { apiKey: "AIzaSyXXXXXXXXXXXXXXXXXX", authDomain: "ruder-challenge-xxxxx.firebaseapp.com", databaseURL: "https://ruder-challenge-xxxxx.firebaseio.com", projectId: "ruder-challenge-xxxxx", storageBucket: "ruder-challenge-xxxxx.appspot.com", messagingSenderId: "123456789012", appId: "1:123456789012:web:xxxxxxxxxxxx" };

✅ Vorteile dieser Methode:

  • ✓ Nur einmal konfigurieren (als Admin)
  • ✓ Alle Nutzer können direkt loslegen
  • ✓ Keine wiederholte Eingabe nötig
  • ✓ Einfacher für deine Freunde

💬 Hinweis: Diese Seite erscheint nur, solange die Konfiguration nicht eingetragen ist. Sobald die Werte im Code stehen, sehen alle Nutzer direkt die App!
