🚣 Firebase Setup

⚠️ Wichtig: Um die App zu nutzen, musst du zuerst deine Firebase-Konfiguration eingeben.

Schritt 1: Firebase Projekt erstellen

1. Gehe zu Firebase Console

2. Klicke auf "Projekt hinzufügen"

3. Name: "Ruder-Challenge" (oder ein beliebiger Name)

4. Google Analytics kannst du deaktivieren

Schritt 2: Realtime Database aktivieren

1. Im linken Menü: "Build" → "Realtime Database"

2. Klicke auf "Datenbank erstellen"

3. Wähle einen Standort (europe-west1 für Europa)

4. Starte im Testmodus (für den Anfang)

Schritt 3: Konfiguration kopieren

1. Gehe zu Projekteinstellungen (Zahnrad-Symbol oben links)

2. Scrolle runter zu "Ihre Apps"

3. Klicke auf das Web-Symbol </>

4. App-Name: "Ruder-Challenge-Web"

5. Kopiere die Konfigurationsdaten

Schritt 4: Konfiguration hier eingeben

💡 Tipp: Sicherheitsregeln anpassen (später)

Nach dem ersten Test solltest du die Sicherheitsregeln anpassen:

{ "rules": { ".read": true, ".write": true } }

⚠️ Diese Regeln erlauben jedem Zugriff. Später kannst du Authentifizierung hinzufügen.
